# FM-GIT-CMD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `:` in `*magit-status*` prompts for a git command, runs it captured, logs a `$` process entry, and shows `*magit-process*`.

**Architecture:** Almost entirely reuse. A new engine `run_git_command(repo, cmdline)` tokenizes (quote-aware, no shell) and runs `detail::run_git` + records a `proclog` entry (mirrors `commit_via_cli`). A one-line bridge C ABI. An editor `:` command that prompts (`eread`), runs it, refreshes status, and opens `*magit-process*` (reusing `magit_process`).

**Tech Stack:** the existing `detail::run_git` (captured `posix_spawn`), `mg::magit::proclog`, the `*magit-process*` buffer, the mg editor (`eread`, keymaps).

## Global Constraints

- **Reuse, don't reinvent:** `run_git` (captured subprocess), `proclog::record`/`argv_to_command`, `magit_process` (the viewer), `eread` (prompt) all exist — use them.
- Runner is **captured `run_git` only** (matches Magit's `:`). Interactive/network commands hang or fail (no tty) — that's the documented limitation; do NOT add tty-routing (deferred: FM-GIT-CMD-TTY).
- Tokenizer: split on unquoted whitespace, honoring `'…'` and `"…"` (literal, no escapes/expansion); empty tokens from real input dropped; an unterminated quote runs to end-of-line (lenient). NO shell.
- A leading `git`/`git ` token in the input is stripped (so both `: status` and `: git status` work).
- `:` is bound in `magit-status-mode` only.
- Verify macOS (`cpp`) + Alpine/musl (`cpp-linux`, Docker) + OFF (`cpp-tsan`).

std::vector<std::string> tokenize_cmdline(const std::string &line)
{
    std::vector<std::string> out;
    std::string cur;
    bool in_tok = false;
    char quote = 0; // 0 = none; else the open quote char
    for (char c : line) {
        if (quote) {
            if (c == quote) quote = 0;     // close quote (keeps in_tok)
            else { cur += c; in_tok = true; }
        } else if (c == '\'' || c == '"') {
            quote = c; in_tok = true;      // open quote ("" yields an empty arg)
        } else if (c == ' ' || c == '\t') {
            if (in_tok) { out.push_back(cur); cur.clear(); in_tok = false; }
        } else {
            cur += c; in_tok = true;
        }
    }
    if (in_tok)
        out.push_back(cur);                // lenient: unterminated quote -> EOL
    return out;
}

int run_git_command(std::string repo, std::string cmdline)
{
    auto args = tokenize_cmdline(cmdline);
    if (!args.empty() && args.front() == "git")
        args.erase(args.begin());          // accept "git status" or "status"
    if (args.empty())
        return -1;
    std::vector<std::string> cmd;          // for the log line: "git <args>"
    cmd.reserve(args.size() + 1);
    cmd.push_back("git");
    for (const auto &a : args) cmd.push_back(a);
    auto t0 = std::chrono::steady_clock::now();
    auto run = detail::run_git(repo, args); // run_git runs `git -C <repo> <args>`
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(
                  std::chrono::steady_clock::now() - t0).count();
    mg::magit::proclog::record('$', mg::magit::proclog::argv_to_command(cmd),
                               run.output, run.code == 0, ms);
    return run.code;
}
```

/* `:` -- run an arbitrary git command; output goes to *magit-process*. */
static int
magit_git_command(int f, int n)
{
	char	cwd[PATH_MAX], cmdline[PATH_MAX];

	if (eread("git: ", cmdline, sizeof(cmdline), EFNEW | EFCR) == NULL ||
	    cmdline[0] == '\0')
		return (ABORT);
	if (getbufcwd(cwd, sizeof(cwd)) != TRUE)
		return (FALSE);
	(void)mg_magit_git_command(cwd, cmdline);
	(void)magit_refresh(f, n);     /* reflect any mutation in *magit-status* */
	return (magit_process(f, n));  /* land on the command's output */
}
```
(`magit_git_command` must be declared after `magit_process`/`magit_refresh` or have forward decls — both already have forward decls earlier in the file; verify.)
